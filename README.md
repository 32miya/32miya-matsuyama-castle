# 松山城さんぽ

現存12天守のひとつ・松山城（愛媛県松山市）の連立式天守と門・櫓群、城下を、スマホで歩いて巡れる3D散策アプリの試作品。three.js製の単一HTMLです（「大阪城さんぽ」「彦根城さんぽ」「備中松山城さんぽ」と同じ仕組み）。

- 時代を選ぶ（メニューの「時代」）: 現代 ⇄ 寛永のころ（1627年に蒲生忠知が城を完成させ、1635年に松平定行が入ったころ）。築城や合戦の体験ツアーはありません
- 史実と伝承・仮説の区別: 寛永のころの天守は「もと五重だった」という言い伝え（『松山叢談』など後世の記録）にもとづく想像復元です。寛永19年（1642年）に松平定行が三重に改めたと伝わりますが、確かな図は残っておらず、はじめから三重だったとする説もあります。解説パネルでもその旨を書いています
- 大手の登城道（江戸時代の正式な道）: 二之丸 → 黒門 → 大手門 → 揚木戸門 → 太鼓櫓の下で折り返し → 戸無門（扉のない高麗門）→ 筒井門（脇の石垣の陰に隠門）→ 太鼓門 → 本丸広場。長者ヶ平（ロープウェイ・リフトの山頂駅）からの道も太鼓櫓の下で合流します
- 本壇（天守曲輪）: 一ノ門 → 二ノ門 → 三ノ門 → 筋鉄門 → 内庭（天守広場）。北からは仕切門 → 内門。天神櫓・一ノ門南櫓・二ノ門南櫓・三ノ門南櫓、仕切門内塀・三ノ門東塀・筋鉄門東塀
- 連立式の天守: 内庭から天守台の地階（穴蔵）に入り、大天守1階へ。1階の西の戸口から 玄関多聞櫓 → 北隅櫓 → 十間廊下 → 南隅櫓 → 多聞櫓 → 小天守 → 筋鉄門の櫓 → 大天守 と、内庭を囲む建物の中をぐるりと一周できます（天守1階の「区画」FL[1].zones）。各階・各櫓の窓は本当に開いていて、中から外の景色が見えます
- 本丸の北: 紫竹門と東西の塀、乾門・乾櫓・乾門東続櫓、野原櫓（現存唯一の望楼型二重櫓）、艮門・艮門東続櫓。乾門からは古町口登城道、艮門からは長者ヶ平へ下る道
- 登り石垣（南北2本）、本丸の大井戸、三之丸（堀之内）と北堀・西堀・南堀
- 現代だけ: ロープウェイとリフト（動きます）、東雲口駅舎とロープウェイ街、天守の券売所・売店、本丸の桜、二之丸史跡庭園（間取りの植え込み・流水園・大井戸遺構）、堀之内公園、萬翠荘、愛媛県庁、大街道、路面電車の線路、西に瀬戸内海（伊予灘）
- 寛永のころだけ: 大手門・揚木戸門・黒門・小筒櫓、二之丸御殿、三之丸の重臣屋敷と門・塀、城下町、番士や城下の人々、松平家の星梅鉢の幟
- 入れる建物: 現代＝二之丸史跡庭園の休憩所・萬翠荘・本丸広場の売店 / 寛永のころ＝二之丸御殿 表書院・太鼓櫓の中・隠門の櫓・三之丸の重臣屋敷・城下の商家
- 松山城専用の絵 `assets/ms_spr.webp`（2048×936）: 描いてもらった1枚の絵から切り抜いて並べ直したもの。屏風・掛軸・床の間・行灯・伊万里の壺・蒔絵の箪笥・長持・文机・刀掛け・槍掛け・太鼓・星梅鉢の陣幕と幟・鬼瓦・金の鯱・天守の絵・高欄・門扉、襖絵（松・桜と鶴・竹と鶴・桜）。位置は index.html の `MSS_META`、置き方は `msPlane` / `msRp`（部屋）/ `msFp`（天守の階）
- 段差は約1.3mまでしか上り下りできません。山の林の斜面には入れず、曲輪・石段・道を歩きます
- 距離と高さは実際よりかなり縮め、建物の配置と寸法も簡略化しています

URLの末尾に `?era=edo` を付けると寛永のころから始まります。

## お城さんぽシリーズ共通
- 人物・旗・襖絵・床板・石垣などの素材は、シリーズ共通の `https://32miya.github.io/oshiro/common/assets/` から読み込みます（このリポジトリに同じ画像を置かない）。一覧と使い方は `32miya/32miya.github.io` の `oshiro/common/README.md`。
- 天守の窓は本当の開口にして、各階の中から外の景色が見えるようにする（シリーズ共通の作り）。天守台の入口は奥の通路が見えるようにあける。天守とつながる建物は中を歩いて行けるようにする。
- index.html の末尾の `oshiro-portal:begin`〜`end` は「お城選びへ戻る」ボタンなので消さない。
- 松山城で新しく作ったもの: 大天守の入口の向きを西にできる `es:-1`（planTenshu）、天守・櫓の外壁 `msSide`（白漆喰＋下見板の腰・連子窓・戸口）、内庭を囲む櫓 `ringBldg`、望楼型二重櫓 `noharaYagura`、登り石垣 `nobori`、扉のない門 `gate(...,{noLeaf:true})`、現代の瓦紋 三つ葉葵 `aoi`。
- 石垣は共通素材の打込接 `stone_uchikomi`（現代は少しくすませた色）、床板は `floor_ita`。

## 作り方（開発用）
`src/` の部品を `build.py` で組み立てて `index.html` を作ります（土台は備中松山城さんぽの仕組み）。`test/` はローカルで歩けるか・階段や渡櫓がつながっているかを確かめるスクリプトです。
